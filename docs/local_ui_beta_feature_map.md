# Local UI Beta Feature Map

## Startup and checks
- Launcher: `scripts/launch_crane_runway_ui.py`
- Beta health check: `scripts/run_beta_health_check.py`
- UI diagnostics: Local UI Diagnostics panel
- RC acceptance check: `scripts/run_local_ui_rc_check.py`

## Case creation and editing
- Templates, project workspace, quick selectors, common inputs, wheel table, raw JSON editor

## Pre-run review
- Visual preview, case quality warnings, validation table, field help/glossary

## Results
- Result cards, result interpretation, HTML report, raw response

## Project workflows
- Run history, run comparison, archive export

## Support and handoff
- Support bundle, issue report helper, beta handoff doc, manual QA checklist

## Current limitations
- no official CIRSOC/CISC/AISC checks
- no fatigue
- no torsional/warping stress checks
- no LTB
- sample data requires independent verification
- engineering review required
