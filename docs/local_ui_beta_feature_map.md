# Local UI Beta Feature Map

## Startup and checks
- Launcher: `scripts/launch_crane_runway_ui.py`
- Beta health check: `scripts/run_beta_health_check.py`
- UI diagnostics: Local UI Diagnostics panel
- RC acceptance check: `scripts/run_local_ui_rc_check.py`

## Case creation and editing
- Templates, project workspace, quick selectors, common inputs, wheel table, raw JSON editor

## Pre-run review
- Visual preview, case quality warnings, validation table, field help/glossary

## Results
- Result cards, result interpretation, HTML report, raw response

## Project workflows
- Run history, run comparison, archive export

## Support and handoff
- Support bundle, issue report helper, beta handoff doc, manual QA checklist

## Current limitations
- no official CIRSOC/CISC/AISC checks
- no fatigue
- no torsional/warping stress checks
- no LTB
- sample data requires independent verification
- engineering review required

## V1-089 tab grouping

- **Home**: Welcome, Guided Demo, Documentation Portal, Guided Workflow, Beta Readiness, RC status, Troubleshooting.
- **Project**: Workspace, Run History, Run Comparison, Archive Export.
- **Inputs**: Quick Selectors, Profile/Material selector, Common Inputs, Input help/glossary.
- **Wheels**: Wheel Table Editor.
- **Preview**: Visual Preview, Case Outline, Case Quality Warnings.
- **Validate & Run**: Validation + run controls.
- **Results**: Result Cards, Summary, Interpretation, HTML Report.
- **Compare**: Scenario Comparison.
- **Export**: Download/Copy + Package Export + archive shortcuts.
- **Support**: About/Beta status, Support Bundle, Issue Report Helper, Diagnostics, shortcuts/limitations.
- **Advanced JSON**: JSON editor/import/format/clear/raw response/autosave.
